# Spec Delta

## Purpose

在既有网页对话入口上补齐两项可用性能力：把回复中的代码块另存为文件（在复制之外多一种取用方式），以及在界面上显示当前会话标识，便于调试与问题定位。

## ADDED Requirements

### Requirement: 代码块另存为文件
系统 SHALL 在代码块的操作区提供「另存为」操作，使使用者能把该代码块的纯文本内容保存为本地文件；文件名 SHALL 依据代码块的语言自动推断扩展名。

#### Scenario: 另存为带语言标识的代码块
- **WHEN** 使用者点击某个已标注语言的代码块上的「另存为」
- **THEN** 系统以该语言对应的扩展名（如 Java 为 `.java`、Python 为 `.py`、JavaScript 为 `.js`）下载一个包含该代码块纯文本的文件

#### Scenario: 同一回复中存在多个同语言代码块
- **WHEN** 同一段回复中出现多个语言相同的代码块并分别另存为
- **THEN** 系统为后续文件追加序号，避免下载文件重名

#### Scenario: 另存为未标注语言的代码块
- **WHEN** 使用者对未标注语言的代码块执行「另存为」
- **THEN** 系统以通用扩展名（`.txt`）下载该代码块内容，不出现异常

#### Scenario: 另存为与复制并存
- **WHEN** 代码块渲染完成
- **THEN** 该代码块同时具备「复制」与「另存为」两个操作，二者互不影响

### Requirement: 当前会话标识展示
系统 SHALL 在界面上显示当前会话的标识，使使用者能够确认自己正在进行哪一段会话。

#### Scenario: 会话建立后显示标识
- **WHEN** 服务端为新会话返回会话标识
- **THEN** 界面显示该标识，并保持与当前会话一致

#### Scenario: 尚无会话时的显示
- **WHEN** 使用者刚打开页面或刚新建会话、尚未产生任何消息
- **THEN** 界面显示表示「尚未创建会话」的占位提示，而不是空白或错误值

#### Scenario: 切换历史会话后同步更新
- **WHEN** 使用者从历史会话列表中切换到另一段会话
- **THEN** 界面上的会话标识同步更新为被切换到的会话标识
