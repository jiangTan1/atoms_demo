# Spec Delta

## Purpose

为项目打包下载补上归属校验：下载目标会话必须属于当前登录用户，他人会话与不存在会话一律按不存在处理，避免经由会话标识枚举下载他人沙箱内容。

## ADDED Requirements

### Requirement: 下载前校验会话归属
系统 SHALL 在打包下载前校验目标会话归属为当前登录用户。归属为他人或不存在时，系统 SHALL 一律按会话不存在处理并返回明确的中文提示，SHALL NOT 打包沙箱内容。

#### Scenario: 下载自己的会话
- **WHEN** 已登录使用者对归属为自己且沙箱非空的会话请求打包下载
- **THEN** 系统返回该会话沙箱内容的压缩包，目录结构保持不变

#### Scenario: 下载他人会话被拒绝
- **WHEN** 已登录使用者以归属为他人的会话标识请求打包下载
- **THEN** 系统按会话不存在处理并返回明确提示，不返回任何文件内容

#### Scenario: 下载不存在的会话
- **WHEN** 已登录使用者以不存在的会话标识请求打包下载
- **THEN** 系统返回明确提示，不产生未处理的异常

#### Scenario: 未登录请求下载
- **WHEN** 未登录使用者请求打包下载
- **THEN** 系统拒绝该请求并要求登录，不返回任何文件内容

### Requirement: 沙箱内容按登录用户隔离
系统 SHALL 保证文件沙箱的读取范围与打包下载范围都限定在当前登录用户名下的会话内，SHALL NOT 允许经由请求参数访问其他用户的沙箱内容。

#### Scenario: 沙箱归属与登录用户一致
- **WHEN** 已登录使用者查看或下载自己会话的沙箱内容
- **THEN** 只能看到归属为自己的会话所产生的文件

#### Scenario: 客户端指定归属者无效
- **WHEN** 请求中带有与登录用户不一致的归属者信息
- **THEN** 系统以登录用户为准，不返回其他用户的沙箱内容
