## 8. 调整：改密只对已登录用户开放

背景：`POST /api/auth/password` 按 access-control spec 要求已登录，而认证界面是未登录状态；先前在前端用「登录 → 改密 → 退出」把两者串起来，会留下短暂的中间登录态且失败路径状态不清。改为「改密只对已登录用户开放，认证界面按钮仅作入口提示」（见 design.md 决策 11）。
