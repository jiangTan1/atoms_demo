# Spec Delta

## Purpose

在既有网页对话入口上补齐交付能力：把智能体已经落盘的项目文件一键打包取走，并在没有可下载内容或下载失败时给出明确提示。

## ADDED Requirements

### Requirement: 下载整个项目
界面 SHALL 在对话区域提供「下载整个项目」入口，使使用者能一次性取走当前会话已生成的全部文件。当该会话沙箱中没有任何文件时，界面 SHALL 给出明确提示而不是发起空下载。

#### Scenario: 有文件时一键下载
- **WHEN** 当前会话已生成若干文件，使用者点击「下载整个项目」
- **THEN** 浏览器下载一个压缩包，解压后得到保留目录结构的全部文件

#### Scenario: 没有文件时的提示
- **WHEN** 当前会话尚未生成任何文件，使用者点击「下载整个项目」
- **THEN** 界面提示当前没有可下载的文件，不触发下载空内容

#### Scenario: 尚未创建会话时的行为
- **WHEN** 使用者刚打开页面、尚未产生任何消息时点击该入口
- **THEN** 界面提示需要先产生会话与文件，不发起无效请求

#### Scenario: 下载失败时的提示
- **WHEN** 打包下载请求失败（如网络异常或服务端错误）
- **THEN** 界面提示失败原因，页面其余功能保持可用

#### Scenario: 切换历史会话后下载目标同步
- **WHEN** 使用者切换到另一段历史会话后点击「下载整个项目」
- **THEN** 下载到的是被切换到的会话的沙箱内容
