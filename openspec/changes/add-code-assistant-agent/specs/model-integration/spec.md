# Spec Delta

## Purpose

定义智能体与大模型之间的接入能力：通过 OpenAI 兼容协议接入大模型服务，并保证配置项、连接失败反馈与密钥管理方式对使用者和运维都是明确且可诊断的。

## ADDED Requirements

### Requirement: OpenAI 兼容端点接入
系统 SHALL 通过 OpenAI 兼容的 HTTP 接口调用大模型，端点地址、模型标识与访问凭据 SHALL 全部来自外部配置，SHALL NOT 将凭据写入源码或提交到版本库。

#### Scenario: 使用配置连接模型
- **WHEN** 已提供有效的端点地址、模型标识与访问凭据
- **THEN** 智能体能够完成一次对话请求并返回模型生成的内容

#### Scenario: 自定义端点地址
- **WHEN** 使用者将端点地址指向另一个 OpenAI 兼容服务
- **THEN** 系统按新的端点地址发起请求，无需修改源码

### Requirement: 配置校验与可诊断错误
当模型配置缺失或连接失败时，系统 SHALL 给出可定位问题的错误信息，指明缺失的配置项或失败的环节，SHALL NOT 以通用异常或静默方式失败。

#### Scenario: 缺少必填配置
- **WHEN** 启动或发起对话时缺少端点地址、模型标识或访问凭据中的任一项
- **THEN** 系统明确指出缺失的具体配置项名称，并拒绝以不完整配置继续请求

#### Scenario: 端点不可达或鉴权失败
- **WHEN** 端点地址不可达，或访问凭据被端点拒绝
- **THEN** 系统在对话侧返回可读的错误说明，区分网络不可达与鉴权失败两类原因，并保留已产生的会话历史

### Requirement: 模型能力开关
系统 SHALL 允许在不修改业务代码的前提下调整模型标识，以便在不同 OpenAI 兼容模型之间切换。

#### Scenario: 切换模型
- **WHEN** 使用者变更配置中的模型标识并重启服务
- **THEN** 后续对话使用新的模型标识，业务逻辑无需改动
