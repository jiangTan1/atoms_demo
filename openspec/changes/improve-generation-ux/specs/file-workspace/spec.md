# Spec Delta

## ADDED Requirements

### Requirement: 从模板初始化会话沙箱
系统 SHALL 支持把一个模板目录的全部内容复制进指定会话的沙箱，使该会话立刻获得一套完整的应用文件；复制 SHALL 只作用于该会话自己的沙箱，SHALL 拒绝任何逃出沙箱的路径，SHALL 受既有沙箱配额约束。复制过程中发生失败时，系统 SHALL NOT 在沙箱内留下半初始化或残缺的内容。

#### Scenario: 复制模板到空沙箱
- **WHEN** 系统把一个模板目录复制进一个尚无内容的会话沙箱
- **THEN** 该会话沙箱内出现模板的全部文件（含入口 `index.html`），且可被预览路由正常提供

#### Scenario: 不越出目标会话
- **WHEN** 系统为某个会话复制模板
- **THEN** 只有该会话的沙箱被写入，其他会话的沙箱与文件不受影响

#### Scenario: 模板不存在
- **WHEN** 请求复制的模板在其模板根目录下不存在
- **THEN** 系统拒绝该操作并给出明确反馈，目标沙箱内容不变

#### Scenario: 复制失败不留残缺
- **WHEN** 复制过程中发生失败（如配额超限或读写错误）
- **THEN** 系统给出失败反馈，并清理本次已复制的内容，不留下残缺沙箱

#### Scenario: 复制受配额约束
- **WHEN** 模板内容超出单文件或单会话配额
- **THEN** 复制被拒绝并给出明确的配额提示，而不是写入超限内容
