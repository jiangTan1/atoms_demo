## 2. 中断与失败重试

- [ ] 2.1 在 `app/services/chat.py` 处理生成协程被取消（`asyncio.CancelledError`）的路径：释放本轮资源、直接结束生成器，不再产出后续帧；确认取消不会被误判为普通异常产出 `error` 帧。验证方式是单元测试模拟取消并断言不产出 `error` 帧、异常正常向上传播
- [ ] 2.2 在 `app/api/chat.py` 收尾处区分「本轮正常结束」与「超时 / 中断」：只有正常结束时才按指纹留档版本；超时与中断路径 SHALL NOT 调用 `snapshot_if_changed`。验证方式是接口测试覆盖「正常轮产生版本」「超时轮不产生版本」「中断轮不产生版本」
- [ ] 2.3 前端 `web/app.js`：用 `AbortController` 支持中断本轮 `fetch`，页面提供「中断」按钮（生成中可见、结束后隐藏），中断后给出「已中断」反馈并刷新预览呈现沙箱实际内容。验证方式是在浏览器中发起一个长任务并点击中断，确认请求停止、提示明确、预览为沙箱现状
- [ ] 2.4 前端 `web/app.js`：对任意 `error` 帧在失败提示附近渲染「重试」按钮，点击后以本轮同一输入重新发起请求；重试成功后移除失败提示。验证方式是在浏览器中断开模型端点制造失败，确认出现重试按钮且点击可重新发起
